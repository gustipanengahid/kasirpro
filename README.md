# 🧾 Kasir Pintar

> **Modern Point of Sale (POS) System** untuk mengelola penjualan, produk, stok, transaksi, dan pengguna dalam satu aplikasi.
>

> ![TypeScript](https://img.shields.io/badge/TypeScript-5-3178C6?style=flat-square&logo=typescript)
> ![Vite](https://img.shields.io/badge/Vite-6-646CFF?style=flat-square&logo=vite)
> ![Supabase](https://img.shields.io/badge/Supabase-Database-3ECF8E?style=flat-square&logo=supabase)

## ✨ Features

- 🛒 **Kasir / POS** — proses transaksi dengan cepat
- 📊 **Dashboard** — ringkasan penjualan & performa toko
- 📦 **Inventory** — kelola produk, kategori, harga & stok
- 🧾 **Transaction History** — melihat riwayat transaksi
- 👥 **User Management** — role Admin, Cashier & Owner
- 🖨️ **Thermal Receipt** — cetak struk transaksi
- 💳 **Multiple Payment** — Cash, QRIS, GoPay, OVO, DANA & ShopeePay
- ⚡ **Realtime Database** — sinkronisasi data menggunakan Supabase
- 📱 **Responsive UI** — nyaman digunakan di berbagai ukuran layar

## 🛠️ Tech Stack

- **React + TypeScript**
- **Vite**
- **Tailwind CSS**
- **Supabase**
- **Lucide React**
- **Recharts**
- **Motion**
